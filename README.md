## 🚀 Quick Start

```bash
# Clone the roster
git clone https://github.com/ziri22/agency-roster.git

# Use with Hermes Agent
cp -r agency-roster/skills/business/* ~/.hermes/skills/business/

# Use with Claude Code
cat agency-roster/skills/business/agent-*/SKILL.md > CLAUDE.md

# Use with any AI — just copy-paste the SKILL.md content
```

## ✅ Compatible With Everything

| Tool | How to Use |
|------|-----------|
| **Hermes Agent** | `cp -r skills/business/* ~/.hermes/skills/business/` |
| **Claude Code** | Copy into `CLAUDE.md` |
| **Cursor** | Paste in `.cursorrules` |
| **ChatGPT** | Use as Custom Instructions |
| **Copilot** | Workspace instructions |
| **Any AI Chat** | Paste the prompt directly |
